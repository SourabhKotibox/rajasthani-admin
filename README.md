# Rajasthan Cine Association

Standalone React UI — **React + React Router DOM + Redux**. No backend. Uses **npm**.

## Run

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173

## Demo logins

- Admin: `admin@rajasthaniacinema.org` / `password123`

## Pages

- Public: Home, Talent directory/profile, Works (Movies / TV / Music Videos / Short Dramas), Casting, About, Contact
- Talent dashboard: profile, portfolio, subscription, applications
- Admin: stats, users, profiles, casting, inquiries

Data is mocked in Redux (`src/data/mock.ts` + `src/store`).
